# 集运通 Demo 设计

> 历史记录：这是最初的纯静态 Demo 设计，后续已实现 Django + PostgreSQL。当前实现、权限与部署方式以项目 README、数据库说明和部署技术方案为准。

目标：为客户演示登录后查看集运包裹位置和运输进度的完整流程。

采用无构建依赖的 HTML、CSS、JavaScript ES Modules，由本地静态服务器运行。所有内容为明确标注的演示数据；登录为本地示例账号，数据由 localStorage 保存，刷新保留。无真实定位、承运商接口或生产级身份认证。

客户视图包括总览、运单查询与状态筛选、可切换运单、示意运输地图、预计送达时间、详细轨迹、包裹信息、收货地址、帮助中心。客户可新增包裹预报。管理员可以更新运单状态、当前位置和轨迹说明，客户视图同步展示。

视觉：中文蓝白物流工作台，窄侧栏、统计卡片、运单卡片与大幅地图，兼容手机；独立登录页提供客户/管理员角色和演示登录。所有可见操作必须有实际反馈，空查询有清晰提示。输入通过 textContent 或 HTML escaping 渲染。弹窗支持关闭与 Escape。

验证：数据模块的搜索、认证、持久化、状态更新使用 Node 内置测试；浏览器验证客户登录、搜索、运单切换、管理员更新、刷新保留和移动视口。
