# Visa Appointment 留学签证预约系统

面向留学教育机构的签证预约机会监测与抢号系统，作为本仓库的独立子项目，与 `projects/parcelink/` 同级维护。

## 当前状态

目前处于系统设计阶段，尚未实现可运行的采集器、后台或预约执行程序，也未接入真实客户账户。当前无需安装依赖、初始化数据库或启动服务。

- 首期范围：法国、德国长期留学签证，以及英国 Student visa。
- 业务规模：同时等待预约的客户不超过 100 人。
- 核心流程：客户资格与授权核验、会话预备、预约机会监测、客户预匹配、低延迟预约执行、人工接管和官方结果核验。
- 渠道差异：直接预约、候补、邀请及无需线下预约分别处理；具体城市、类别与渠道能力在接入时核验。

## 项目组织

本项目的业务代码、依赖、环境配置、数据库、部署文件和文档统一放在 `projects/visa-appointment/` 内维护。后续实现时补充实际安装、启动、测试和部署说明。

仓库根目录统一管理 Git；本目录不创建嵌套 Git 仓库。项目使用独立环境和数据卷，CI 按项目路径触发。客户证件、密码、Cookie、OTP、真实材料和私有环境文件不提交到仓库。
